## 一、开发的桌面为什么总是这么乱

做嵌入式开发，尤其是经常跟通信模组（4G Cat.1、WiFi、蓝牙、GPS）打交道的同学，桌面上永远是这一幕：

- 一个串口接模组 **AT 指令口**
- 一个接 **MCU 日志口**
- 一个接 **传感器 / 调试口**
- ……

<img src="/images/自制%20FT4232H%20四路串口调试器/0.jpg" style="width:500px;"><br>

结果就是：**USB 口被一堆 CH340、CP2102 小板占满，线缠成一团，还动不动掉盘、插拔一次 COM 号就变。**

## 二、FT4232H 四路串口优势

| 对比项          | 单路 CH340 / CP2102 小板 | **本工具（FT4232H）**                      |
| ------------ | -------------------- | ------------------------------------- |
| 一路 USB 出几个串口 | 1 个                  | **4 个**（A/B/C/D 独立 COM）               |
| 桌面线缆         | 每路一根 USB 小板          | **一根 Type-C 搞定**                      |
| 连接线材         | 专用 USB 线             | **Type-C 数据线 / PH2.0 鼠笼线（兼容鼠标线）**     |
| 供电与结构        | 多为直插 / 外露焊盘          | **全贴片（SMT），底板平整无焊盘**                  |
| 误触发风险        | 焊盘 / 引脚外露易短路         | 无外露焊盘，**不会误触发**                       |
| 驱动稳定性        | 杂牌芯片常掉盘、COM 号乱跳      | **FTDI 官方 VCP 驱动，长期稳定**               |
| 端口固定         | 基本靠运气                | 配 EEPROM + Serial Number，**端口顺序永久固定** |
| 🌟 双向监听      | 不支持（需两路 / 逻辑分析仪）     | **二极管线与，一个助手同时看 TX+RX**               |

## 三、🌟 集成线与监听（一个窗口看双向报文）
调试通信模组（MCU ↔ 模组）时，想同时看 TX 和 RX 报文，要么开两个串口助手手动拼时序，要么搬出逻辑分析仪 —— 都太重了。

### 3.1 传统做法的麻烦

调试 MCU ↔ 通信模组时，链路是：

```
MCU:TX ──── 模组:RX
MCU:RX ──── 模组:TX
```

想完整分析一帧协议（MCU 发了什么、模组回了什么），传统方案：

- **方案 A**：用两个串口分别抓 MCU 和模组 → 两个串口助手**时间戳难对齐**，还得手动拼
- **方案 B**：搬逻辑分析仪 → 太重，还得额外软件

### 3.2 本工具的监听原理

带2路 **3Pin 监听接口**，用**两个二极管把 MCU→模组 和 模组→MCU 两条线"合并"成一个 RX**：

## 四、硬件简介

<img src="/images/自制%20FT4232H%20四路串口调试器/SCH.png" style="width:1000px;"><br>


**主要特性速览：**

- ✅ 4 路独立 UART（A/B/C/D），每路引出 **VOUT / TX / RX / GND**
- ✅ 每路**电平转换**，兼容  3.3 / 5V 目标板
- ✅ 每路**流量 LED 指示**（74HC595 驱动）
- ✅ 带2路 **3Pin 通信模组收发监听接口**（二极管线与）
- ✅ USB Type-C 母座 + PH2.0 鼠笼线（兼容鼠标线）两种连接方式
- ✅ **全贴片、单面布局，底板无焊盘**

**关键元件表：**

| 位号 | 型号 | 作用 |
|---|---|---|
| U1 | FT4232HL-Reel (LQFP-64) | 主芯片，出 4 个 COM |
| U2 | TXS0108E | 8 位双向电平转换 |
| U4 | AMS1117-3.3 兼容 | 3.3V LDO |
| U5 | 93LC56B | 配置 EEPROM（固定端口名） |
| U6 | 74HC595D | LED 流量灯驱动 |
| X1 | 12MHz 3225 | 主时钟 |
| D1/D2... | SOT-23 开关二极管 | 监听"线与" |
