# 自定义样式配置笔记

> 换电脑后按此笔记恢复配置。Obsidian 预览和 Hexo 博客效果一致。

## 样式效果

章节标题：左侧蓝色竖条 + 底部蓝色下划线 + 加粗文字。

## 使用方法

在 Markdown 文章里写：

```html
<div class="section-title">标题文字</div>
```

## CSS 代码

```css
/* 自定义章节标题：左侧竖条 + 底部下划线 */
.section-title {
  border-left: 4px solid #2196F3;
  border-bottom: 2px solid #2196F3;
  padding: 6px 14px;
  margin: 18px 0;
  font-size: 20px;
  font-weight: bold;
  color: #1A1A1A;
  line-height: 1.6;
}
```

## Obsidian 配置

1. 把上面 CSS 保存为文件：`<vault>/.obsidian/snippets/section-title.css`
2. Obsidian → 设置 → 外观 → 拉到「CSS 代码片段」→ 点刷新按钮
3. 打开 `section-title` 开关

## Hexo 配置

把上面 CSS 追加到主题样式文件末尾：

```
themes/pure/source/css/style.css
```

然后重新生成：

```bash
hexo clean && hexo g
```

# 彩色标题（仿飞书，可指定颜色）

## 样式效果

纯色加粗标题文字，无竖条无边框，颜色默认主题蓝，可任意指定。

## 使用方法

在 Markdown 文章里写（不写颜色时默认蓝色）：

```html
<div class="color-title">一、AES 是什么</div>
```

指定颜色（用 `--title-color` 传色值）：

```html
<div class="color-title" style="--title-color: #E05656;">一、AES 是什么</div>
```

## CSS 代码

```css
/* 自定义彩色标题：仿飞书标题，颜色可指定（默认主题蓝） */
.color-title {
  color: var(--title-color, #2196F3);
  font-size: 20px;
  font-weight: 700;
  line-height: 1.5;
  margin: 20px 0 12px;
  padding: 0;
  border: none;
}
```

## 配置位置

和 `section-title` 完全一样，两处都要加：

1. **Obsidian**：追加到 `<vault>/.obsidian/snippets/section-title.css`（同一个文件，同一个开关）
2. **Hexo**：追加到 `themes/pure/source/css/style.css` 末尾，然后 `hexo clean && hexo g`

# 彩色标题内联版（进目录版）

## ⚠️ 重要说明

`<div class="color-title">` 不是标题标签，**不会出现在 `<!-- toc -->` 目录里**。
需要进目录时，用下面的内联版写法（`##` 标题 + 彩色 span）。

## 使用方法

```markdown
## <span class="color-title-inline">一、AES 是什么</span>
```

指定颜色：

```markdown
## <span class="color-title-inline" style="--title-color: #E05656;">一、AES 是什么</span>
```

## CSS 代码

```css
/* 彩色标题内联版：配合 ## 标题使用，可进目录，颜色可指定 */
.color-title-inline {
  color: var(--title-color, #2196F3);
}
```

## 配置位置

和上面一样，追加到 Obsidian snippet 和 Hexo `style.css` 末尾。

## ⚠️ 已知坑：标题里嵌 HTML 会导致目录链接错误（已修复）

`## <span class="...">标题</span>` 这种写法，hexo-toc 生成目录链接时会**把 HTML 标签名和 class 拼进 slug**，
导致目录 href 指向不存在的 id（如 `#span-classcolor-title-inline一-aes-是什么span`），点击不跳转。

**已在 `themes/pure/layout/_widget/toc.ejs` 修复**：目录不再用 hexo-toc 预生成的链接，
改为运行时从正文真实标题的 span id 重建，href 必然和标题 id 匹配。
**目录支持 `#` ~ `######` 全部六级标题**（h1~h6 都进目录）。

**换电脑恢复时**：toc.ejs 的这段修复也要一起带上（位于"2. Rebuild TOC from real headings"注释处）。

## 两种用法的选择

| 场景 | 写法 |
|---|---|
| 标题要进 `<!-- toc -->` 目录 | `## <span class="color-title-inline">标题</span>` |
| 独立装饰标题（不进目录） | `<div class="color-title">标题</div>` |
