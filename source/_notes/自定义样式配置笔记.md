# 自定义样式配置笔记

> 换电脑后按此笔记恢复配置。Obsidian 预览和 Hexo 博客效果一致。

## 样式效果

章节标题：左侧蓝色竖条 + 底部蓝色下划线 + 加粗文字。

## 使用方法

在 Markdown 文章里写：

```html
<div class="section-title">标题文字</div>
```

## CSS 代码

```css
/* 自定义章节标题：左侧竖条 + 底部下划线 */
.section-title {
  border-left: 4px solid #2196F3;
  border-bottom: 2px solid #2196F3;
  padding: 6px 14px;
  margin: 18px 0;
  font-size: 20px;
  font-weight: bold;
  color: #1A1A1A;
  line-height: 1.6;
}
```

## Obsidian 配置

1. 把上面 CSS 保存为文件：`<vault>/.obsidian/snippets/section-title.css`
2. Obsidian → 设置 → 外观 → 拉到「CSS 代码片段」→ 点刷新按钮
3. 打开 `section-title` 开关

## Hexo 配置

把上面 CSS 追加到主题样式文件末尾：

```
themes/pure/source/css/style.css
```

然后重新生成：

```bash
hexo clean && hexo g
```

## 可调参数

| 参数 | 位置 | 说明 |
|---|---|---|
| `#2196F3` | border-left / border-bottom | 竖条和下划线颜色 |
| `4px` | border-left | 竖条粗细 |
| `2px` | border-bottom | 下划线粗细 |
| `20px` | font-size | 标题字号 |
